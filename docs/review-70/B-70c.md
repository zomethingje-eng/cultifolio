## 2. `--fill wikidata`

**IPNI.** An item's IPNI identifier now refuses it only when Kew holds that identifier for another author's name (the homonym). Any other IPNI is no evidence either way, and the GBIF keys decide.
- To keep the homonym cases refused, a GBIF key whose record is another author's name of these words now refuses the item, just as the IPNI would.
- Raphionacme linearis and Convolvulus cneorum stay refused, and their tests are unchanged.

**Matucana gigantea.** The IPNI identifier is now read out of the address form (`ipniId`), so it equals Kew's.

**Ixora coccinea.** The cause is GBIF's backbone, which cites the species as "Comm. ex Lam.". Kew holds that name as a synonym of *Embothrium coccineum*, which is in the Proteaceae.
- That is why the live page shows Embothrium's range: Chile South, Chile Central and Argentina South.
- It is also why the item carrying Kew's *Ixora coccinea* L. (753844-1) was read as another author's.
- **Fix:** Kew's rows are now read within the species' family (`inFamily` in `authors.ts`), both in the bulk range reading and in `kewIpni`.
  - This applies only where Kew has a row of these words in the species' family, so a family that GBIF and Kew name differently changes nothing (there is a guard test for this).
- `--list-rebuild` now passes the family too, so Ixora coccinea goes onto `rebuild-keys.txt`.

**"No item (none)".** I checked Fragaria virginiana; the other ~19 still need the list.

- It carries Miller's 318974-2. Kew holds Duchesne's name (the backbone's) as a synonym of *F. virginiana* subsp. *virginiana*, which belongs to Miller's species.

### Fixes the run called for (commit `4f5db01`)

1. **Reading IPNI identifiers.** An IPNI identifier that Kew does not hold is now read at IPNI itself (`/api/1/n/<id>`, at most two per item). The item is proved by:
   - IPNI's record of these words by the backbone's author, or by the author of Kew's own row;
   - IPNI's isonym of Kew's record.

   Any other identifier is no evidence, as you decided. This fixed:
   - Ipomoea lobata: 269217-1 is IPNI's duplicate of Thell.'s name.
   - Agave applanata: "Lem. ex Jacobi" is an isonym of K.Koch's.
   - Gymnocalycium hossei: IPNI's "A.Berger" matches Kew's "(F.Haage) A.Berger".
   - Begonia grandis: IPNI spells the name "grandes".
2. **Reading authors.**
   - Initials in a row: "S.Mc Cabe" and "S.W.McCabe" are one author (Dudleya gnoma).
   - "Krainz ex Shurly" cited as "Krainz" is the same name (Mammillaria pennispinosa).
   - One person in both citations makes them one name: "A.Cunn. ex Mudie" and "A.Cunn. & C.Fraser" (Castanospermum australe).
3. **GBIF keys of another author's name.** Such a key refuses the item. This is needed because Kew does not hold N.E.Brown's name, so the IPNI cannot refuse Raphionacme linearis. Two exceptions:
   - a record GBIF files under this species;
   - a record filed under this species' epithet in another genus, which proves the item (Philodendron bipinnatifidum, filed under Thaumatophyllum).
4. **Labels and Kew rows.**
   - A label spelt otherwise counts as the label (Nepenthes burbidgeae).
   - Kew's hybrid rows are not the species' words: "Rubus ×parviflorus" is not "Rubus parviflorus".
   - `--fill wikidata` now gives a bare "no item" its reason (`NO_ITEM`).
