#   npx tsx scripts/bulk-fetch.ts gbif-flowering --wait

# When: after a day's daily run has stopped, never at midnight UTC. The fill is offline and takes minutes.
#
# The dry run counts every page and writes none: it compares the download's counts with the API's on every page the API
# read (bulk/flowering-compare.tsv), and the first review stops on the plan's conditions. The second stops whatever the
# figures, so the pages sharply apart are read with Claude before any page is written (decision 2: a synonym GBIF files
# under another key is fixed by the extra-keys rule for every page; otherwise the download's figure stands). Then
# --go-on writes every page, indexes, uploads and checks the live site. The backup first, so the API's counts can be put
# back if anything is wrong after the write.

Measured on 14 November 2026 against the download of 21 October: the median ratio 0.79, the peak month within a month on 92.1%, and the taxon mismatches. Stop, and paste the end of corpus-step.log back, if the peak month is within one month on fewer than 85% of the pages with 30 or more from the API, if the median ratio is below 0.6, if more than 2% of the pages with over 100 from the API have none in the download, if K is over 1,000 (2,354 pages have no GBIF key of their own and 1,419 of them read the keys Kew's synonymy gives them), or if a line says "not counted, nothing written".
